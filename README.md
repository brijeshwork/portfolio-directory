# Portfolio Directory

An open, community-maintained directory of personal portfolios for inspiration.

Whether you are preparing a job search, refreshing your personal brand, or looking for ideas for a case study, this directory makes it easy to explore how people present their work.

## Explore portfolios

| Directory | For portfolios by people working in |
| --- | --- |
| [Developer Portfolios](portfolios/developers.md) | software engineering, data, AI, DevOps, mobile, and related technical fields |
| [PM Portfolios](portfolios/product-managers.md) | product management, growth, product operations, and technical product roles |
| [Designer Portfolios](portfolios/designers.md) | product design, UX, UI, research, brand, motion, and visual design |

## How it works

Each category is a Markdown file. A portfolio can appear in more than one category when that reflects the person's work, such as a developer-designer or a product designer who also works in product management.

Every entry uses this format:

```md
- [Name](https://portfolio.example) — Short role or specialty
```

For example:

```md
- [Avery Chen](https://averychen.example) — Product designer focused on fintech
```

Entries are grouped alphabetically by the person's first name. Markdown is the only source of truth: there is no JSON database or generated feed to maintain.

## Add your portfolio

Please read [CONTRIBUTING.md](CONTRIBUTING.md), add your live portfolio to the most relevant category file, and open a pull request. A concise role or specialty helps visitors decide what to explore.

## Principles

- **Useful inspiration:** Link to a personal portfolio or case-study site, not a social-media profile, template listing, or company homepage.
- **Clear organization:** Keep entries in alphabetical order within each category.
- **Inclusive categories:** Cross-list a portfolio when it has meaningful work in more than one field.
- **Working links:** Submit only links you have opened and verified.
