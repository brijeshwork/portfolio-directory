# Contributing

Thanks for helping make this directory useful.

## Add a portfolio

1. Fork this repository and create a branch for your change.
2. Choose one or more relevant files in [`portfolios/`](portfolios/):
   - `developers.md`
   - `product-managers.md`
   - `designers.md`
3. Add your entry under the letter matching your first name, in alphabetical order.
4. Use this exact format:

   ```md
   - [Your Name](https://your-portfolio.example) — Your role or specialty
   ```

5. Open the link in a browser to confirm that it loads and is not a parked or for-sale domain.
6. Open a pull request with a short, descriptive title such as `Add Priya Shah to PM portfolios`.

## Submission checklist

- [ ] The link leads to a live personal portfolio or case-study website.
- [ ] I chose the appropriate category or categories.
- [ ] My entry is alphabetized by first name in every file I changed.
- [ ] My entry follows the required Markdown format.
- [ ] I did not add personal contact details beyond those already displayed on the linked portfolio.

## Category guidance

| Category | Include portfolios primarily showing |
| --- | --- |
| Developers | engineering projects, technical work, open-source contributions, data/AI, infrastructure, or developer experience |
| Product managers | product strategy, discovery, launches, roadmaps, growth experiments, outcomes, or product case studies |
| Designers | UX/UI, product design, research, visual design, motion, brand, accessibility, or design case studies |

Cross-listing is welcome when it accurately describes the portfolio. Do not create a duplicate entry in the same file.

## Maintainer notes

The Markdown lists are the source of truth. Keep changes focused: do not reformat unrelated entries, and do not add generated data files.
